### 數據標記與說明

* **標記規則**：所有數據均已依照**時間**與**人員**進行標記。
* **地點判定**：若數據未特別標記地點，則預設為**三汀山數據**。

---

### 資料夾與數據狀態

* **說明文件**：部分資料夾內包含 `README.md`，記載該批數據的詳細狀態。
* **處理狀況**：多數數據皆已完成預處理，確認無誤。
* **數據還原**：若需要將數據還原至原始狀態，可使用 `refresh.py` 腳本進行處理。

---

### 原始數據架構說明

原始數據格式總共包含 13 個維度的感測器數值，欄位之間以底線 `_` 區隔，並以 `end` 作為該筆資料的結尾標記。詳細架構如下：

$$\text{加速度} \times 3 + \text{陀螺儀} \times 3 + \text{磁力計} \times 3 + \text{四元數} \times 4 + \text{"end"}$$

* **詳細欄位順序**：
  `[Acc_X]_[Acc_Y]_[Acc_Z]_[Gyro_X]_[Gyro_Y]_[Gyro_Z]_[Mag_X]_[Mag_Y]_[Mag_Z]_[Q_w]_[Q_x]_[Q_y]_[Q_z]_end`
